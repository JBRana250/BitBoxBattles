## About BitBoxBattles
Have you ever seen those vids on YouTube, the ones where there are two guys just fighting each other in a square arena, bouncing off the arena walls and doing all kinds of shenanigans?

BitBoxBattles is a game that basically simulates these fights, with one key twist:

You can create your own fighters!

## Features

* There is an intro sequence when the fight starts where you can choose the fighters
* Fighter creation through an intuitive node-based interface
  - Events, Actions and Conditional nodes allow for modular design
  - Image and Audio files can be imported straight from the Downloads folder
